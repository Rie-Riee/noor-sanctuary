# Noor Sanctuary — Islamic Lifestyle Ecosystem

Aplikasi ekosistem gaya hidup islami modern berbasis Flutter yang dirancang untuk mendampingi ibadah harian seluruh anggota keluarga Muslim secara terpadu, hening, dan berkesinambungan.

🌐 **Live Web Demo:** [https://rie-riee.github.io/noor-sanctuary/](https://rie-riee.github.io/noor-sanctuary/)

---

## 🌟 Fitur Utama (Sanctuary Modes)

### 1. 🌿 General Sanctuary (Universal & Keluarga)
- **Jadwal Sholat Realtime**: Perhitungan waktu sholat 5 waktu otomatis berdasarkan koordinat waktu setempat dengan hitung mundur waktu adzan.
- **Mutaba'ah & Habits Yaumiyah**: Pelacak target ibadah harian (sholat sunnah rawatib, dhuha, tahajjud, dzikir pagi-petang, tilawah, dan sedekah subuh).
- **Mushaf Digital 30 Juz**: Teks Al-Qur'an lengkap bersanad dengan terjemahan Bahasa Indonesia, pencarian cepat surah, dan audio tilawah qari ternama.
- **Arah Kiblat Presisi**: Kompas kiblat interaktif penunjuk derajat Ka'bah.

### 2. 🌸 Sisterhood Sanctuary (Muslimah & Thaharah)
- **Siklus Thaharah & Haidh**: Kalender pencatatan siklus suci dan haid otomatis dengan kalkulasi masa subur dan prediksi hari bersih.
- **Rukhsah & Amalan Pengganti**: Rekomendasi amalan bernilai pahala bagi muslimah yang berhalangan sholat (dzikir, shalawat, menyimak kajian, sedekah).
- **Pengingat Qadha Puasa**: Tracker hutang puasa Ramadhan agar tuntas sebelum Ramadhan berikutnya.

### 3. ⭐ Kids Sanctuary (Ruang Ceria & Edukatif Anak)
- **Belajar Hijaiyah Bersuara**: Mengenal huruf hijaiyah dengan audio pelafalan makhraj interaktif.
- **Kisah 25 Nabi Bergambar**: Kisah teladan para rasul dalam format narasi ilustratif.
- **Celengan Bintang Pahala**: Gamifikasi apresiasi kebaikan anak setiap kali menyelesaikan amalan.
- **Proteksi PIN Orang Tua**: Sistem keamanan PIN 4-digit untuk menjaga sesi anak tetap aman dan terarah.

### 4. 🎮 Khazanah Games (Arena Belajar Interaktif)
- **Kuis Sambung Ayat**: Tantangan hafalan ayat Al-Qur'an dengan scoring dan evaluasi.
- **Petualangan Sirah & Fiqih**: Kuis edukasi sejarah peradaban Islam dan pemahaman syariat dasar.

### 5. 🎬 Khazanah Media (Syiar Digital Bebas Iklan)
- **Syiar 60 Detik**: Video vertikal inspiratif penyejuk hati berdurasi ringkas.
- **Kajian Sinematik & Podcast Qolbu**: Dokumenter sejarah Islam dan audio doa pengantar istirahat malam.

## 💻 Tech Stack & Arsitektur

- **Framework**: Flutter (Multi-platform: Web, Android, iOS, Desktop)
- **Bahasa Pemrograman**: Dart 3.x
- **Desain UI/UX**: Material Design 3, Google Fonts (Syne, Plus Jakarta Sans, Scheherazade New)
- **Pendekatan Arsitektur**: Clean Component-Based Widgets & Responsive Layouts (Desktop Widescreen & Mobile Adaptive)

## 🚀 Panduan Menjalankan Aplikasi Secara Lokal

### Prasyarat
- Flutter SDK (versi 3.22 atau lebih baru)
- Browser Google Chrome / Edge

### Langkah Instalasi
```bash
# 1. Clone repositori ini
git clone https://github.com/Rie-Riee/noor-sanctuary.git

# 2. Masuk ke direktori proyek
cd noor-sanctuary

# 3. Unduh seluruh dependensi paket
flutter pub get

# 4. Jalankan aplikasi pada browser Chrome
flutter run -d chrome
```
